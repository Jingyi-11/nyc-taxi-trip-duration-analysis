# Data

This repository includes the small TLC taxi zone lookup table used for decoding location IDs.

The raw trip record file is not included because it is large. Download the January 2026 Yellow Taxi Trip Records parquet file from the NYC Taxi and Limousine Commission trip record data portal and place it at the project root:

```text
yellow_tripdata_2026-01.parquet
```

Expected file:

```text
yellow_tripdata_2026-01.parquet
```
